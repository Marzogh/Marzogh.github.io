    <i aria-hidden="true">↓</i>
  </a>

  <CodeDisclosure sourcePath="public/assets/downloads/download_pdfs_crawl_site.py" lang="python" />

```bash
python -m pip install requests beautifulsoup4
python download_pdfs_crawl_site.py "https://example.com/start-page"
```

  <p>It follows links on the same domain and downloads the PDFs it finds. You can also stop it wandering too far:</p>

```bash
python download_pdfs_crawl_site.py "https://example.com/start-page" "my_pdfs" --max-pages 25 --max-depth 2
```

  <a className="downloader-button" href="/assets/downloads/download_pdfs_selenium.py" download>

    <i aria-hidden="true">↓</i>
  </a>

  <CodeDisclosure sourcePath="public/assets/downloads/download_pdfs_selenium.py" lang="python" />

```bash
python -m pip install requests beautifulsoup4 selenium
python download_pdfs_selenium.py "https://example.com/javascript-page"
```

  <p>This uses headless Chrome to render the page before looking for PDF links. Chrome needs to be installed; recent Selenium versions can normally sort out the matching driver themselves.</p>

  <p>For slower pages:</p>

```bash
python download_pdfs_selenium.py "https://example.com/javascript-page" "my_pdfs" --wait 8
```
