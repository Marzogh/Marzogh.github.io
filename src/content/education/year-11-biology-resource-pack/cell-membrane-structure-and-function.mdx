## Overview

A general-purpose lesson on the fluid mosaic model and how membrane structure controls movement.

## Learning Goals

- describe phospholipid bilayer structure
- explain roles of membrane proteins and cholesterol
- relate selective permeability to cell survival

## Worked Example

If a molecule is small and non-polar, predict movement across the membrane: it diffuses directly through the phospholipid core without transport proteins.

## Check For Understanding

- Why is the membrane called selectively permeable?
- Which membrane features affect permeability?
- How does the model explain transport differences between substances?

## Common Misconceptions To Address

- membranes are rigid walls
- all substances cross at equal rates
- proteins are optional in membrane transport

## Teaching Sequence (Suggested)

1. Start with retrieval questions from prior lessons.
2. Model one example step by step using scientific vocabulary.
3. Run guided practice with immediate feedback.
4. Move to independent application.
5. End with an exit task that requires evidence-based reasoning.

## Adaptation Notes

- Support: sentence starters, partially completed diagrams, key-term banks.
- Extension: unfamiliar data, compare-and-justify prompts, evaluate limitations.
- Assessment alignment: include one short-response and one extended-response item.
