## Overview

A practical guide for investigating catalase activity using oxygen production under varied conditions.

## Learning Goals

- design a fair test for enzyme rate
- measure and graph reaction rate data
- evaluate anomalies and methodological limitations

## Worked Example

In a catalase-hydrogen peroxide setup, oxygen volume collected over time provides a rate measure; steeper initial slope indicates faster enzyme activity.

## Check For Understanding

- Which variable changes in your trial set?
- How will you calculate rate consistently?
- What might explain outlier trials?

## Common Misconceptions To Address

- final volume equals reaction rate
- bubbling intensity alone is enough evidence
- graph shape is irrelevant to interpretation

## Teaching Sequence (Suggested)

1. Start with retrieval questions from prior lessons.
2. Model one example step by step using scientific vocabulary.
3. Run guided practice with immediate feedback.
4. Move to independent application.
5. End with an exit task that requires evidence-based reasoning.

## Adaptation Notes

- Support: sentence starters, partially completed diagrams, key-term banks.
- Extension: unfamiliar data, compare-and-justify prompts, evaluate limitations.
- Assessment alignment: include one short-response and one extended-response item.
