## Overview

A reusable lesson on innate barriers, inflammatory responses, and adaptive immune specificity.

## Learning Goals

- describe first, second, and third lines of defence
- compare innate and adaptive responses
- interpret primary vs secondary immune response patterns

## Worked Example

On first exposure, antibody levels rise slowly; on re-exposure, memory cells trigger a faster, larger response, reducing disease severity.

## Check For Understanding

- Which responses are non-specific versus specific?
- What role do memory cells play?
- Why do vaccines reduce severe outcomes?

## Common Misconceptions To Address

- adaptive immunity acts first
- antibodies kill pathogens directly in all cases
- immune memory appears instantly after first exposure

## Teaching Sequence (Suggested)

1. Start with retrieval questions from prior lessons.
2. Model one example step by step using scientific vocabulary.
3. Run guided practice with immediate feedback.
4. Move to independent application.
5. End with an exit task that requires evidence-based reasoning.

## Adaptation Notes

- Support: sentence starters, partially completed diagrams, key-term banks.
- Extension: unfamiliar data, compare-and-justify prompts, evaluate limitations.
- Assessment alignment: include one short-response and one extended-response item.
