## Overview

A practical resource investigating how pectinase affects juice yield or clarity under controlled conditions.

## Learning Goals

- write a testable hypothesis for enzyme action
- identify independent, dependent, and controlled variables
- evaluate reliability and validity of practical data

## Worked Example

If equal fruit masses are treated with pectinase and control solution, greater filtrate volume in treated samples indicates enzymatic breakdown of pectin in cell walls.

## Check For Understanding

- Which variable must be controlled most tightly?
- How do repeats improve reliability?
- What evidence supports your conclusion?

## Common Misconceptions To Address

- single-trial data are sufficient
- control groups are optional
- higher yield automatically proves perfect method design

## Teaching Sequence (Suggested)

1. Start with retrieval questions from prior lessons.
2. Model one example step by step using scientific vocabulary.
3. Run guided practice with immediate feedback.
4. Move to independent application.
5. End with an exit task that requires evidence-based reasoning.

## Adaptation Notes

- Support: sentence starters, partially completed diagrams, key-term banks.
- Extension: unfamiliar data, compare-and-justify prompts, evaluate limitations.
- Assessment alignment: include one short-response and one extended-response item.
