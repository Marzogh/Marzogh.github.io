## Overview

A reusable lesson on nephron anatomy and the processes of filtration, selective reabsorption, and urine formation.

## Learning Goals

- label nephron structures accurately
- explain where major kidney processes occur
- relate nephron function to osmoregulation

## Worked Example

Ultrafiltration occurs at the glomerulus; useful solutes are selectively reabsorbed in the tubules; water balance is adjusted in collecting ducts under hormonal influence.

## Check For Understanding

- Which substances are filtered but later reabsorbed?
- How is selective reabsorption different from filtration?
- How does ADH influence final urine concentration?

## Common Misconceptions To Address

- kidneys filter blood once and immediately excrete all filtrate
- proteins normally pass through glomerular filters
- osmoregulation is unrelated to nephron structure

## Teaching Sequence (Suggested)

1. Start with retrieval questions from prior lessons.
2. Model one example step by step using scientific vocabulary.
3. Run guided practice with immediate feedback.
4. Move to independent application.
5. End with an exit task that requires evidence-based reasoning.

## Adaptation Notes

- Support: sentence starters, partially completed diagrams, key-term banks.
- Extension: unfamiliar data, compare-and-justify prompts, evaluate limitations.
- Assessment alignment: include one short-response and one extended-response item.
