## Overview

A reusable fieldwork guide on quadrats, transects, replication, and bias control in ecological investigations.

## Learning Goals

- select appropriate sampling strategy for a question
- justify sample size and replication
- identify and reduce bias in field protocols

## Worked Example

Belt transects are suitable for studying changes across environmental gradients because they systematically sample along a defined line and capture spatial pattern shifts.

## Check For Understanding

- When is random sampling preferred over systematic sampling?
- How does replication improve confidence?
- Which biases are most likely in this field setup?

## Common Misconceptions To Address

- random means unsystematic and careless
- more sites always compensates for poor method design
- bias only occurs during data analysis

## Teaching Sequence (Suggested)

1. Start with retrieval questions from prior lessons.
2. Model one example step by step using scientific vocabulary.
3. Run guided practice with immediate feedback.
4. Move to independent application.
5. End with an exit task that requires evidence-based reasoning.

## Adaptation Notes

- Support: sentence starters, partially completed diagrams, key-term banks.
- Extension: unfamiliar data, compare-and-justify prompts, evaluate limitations.
- Assessment alignment: include one short-response and one extended-response item.
