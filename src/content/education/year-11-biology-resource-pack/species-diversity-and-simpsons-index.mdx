## Overview

A general lesson on biodiversity measurement using richness, evenness, and Simpson-based indices.

## Learning Goals

- define species richness and evenness
- calculate and interpret Simpson-based metrics
- compare site diversity using quantitative evidence

## Worked Example

Two sites can have equal richness but different evenness; the site with more even species proportions has greater effective diversity.

## Check For Understanding

- Why are richness and evenness both required?
- What does a diversity index value indicate?
- How would sampling effort affect your interpretation?

## Common Misconceptions To Address

- index calculations replace ecological interpretation
- more individuals always means higher diversity
- one sample is enough for site-level conclusions

## Teaching Sequence (Suggested)

1. Start with retrieval questions from prior lessons.
2. Model one example step by step using scientific vocabulary.
3. Run guided practice with immediate feedback.
4. Move to independent application.
5. End with an exit task that requires evidence-based reasoning.

## Adaptation Notes

- Support: sentence starters, partially completed diagrams, key-term banks.
- Extension: unfamiliar data, compare-and-justify prompts, evaluate limitations.
- Assessment alignment: include one short-response and one extended-response item.
