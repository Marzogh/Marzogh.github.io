## Overview

A reusable lesson on regulation around set points with receptor-control-effector pathways and negative feedback.

## Learning Goals

- define homeostasis and set point
- map negative feedback loops
- explain consequences of failed regulation

## Worked Example

In thermoregulation, increased body temperature activates sweating and vasodilation; heat loss reduces temperature toward set point, then responses diminish.

## Check For Understanding

- What is the role of receptors, control centre, and effectors?
- Why is negative feedback stabilizing?
- How is positive feedback different?

## Common Misconceptions To Address

- homeostasis means no variation at all
- negative feedback makes change larger
- all control systems are hormonal only

## Teaching Sequence (Suggested)

1. Start with retrieval questions from prior lessons.
2. Model one example step by step using scientific vocabulary.
3. Run guided practice with immediate feedback.
4. Move to independent application.
5. End with an exit task that requires evidence-based reasoning.

## Adaptation Notes

- Support: sentence starters, partially completed diagrams, key-term banks.
- Extension: unfamiliar data, compare-and-justify prompts, evaluate limitations.
- Assessment alignment: include one short-response and one extended-response item.
