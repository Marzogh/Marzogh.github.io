  <section data-zenit-story>
    <h2>Zenit-12XP / Zenit-12SD manuals</h2>
    <aside class="zenit-specplate zenit-specplate--aside" aria-label="Zenit-12XP at a glance">
      <h3>Zenit-12XP at a glance</h3>
      <dl>
        <div><dt>Type</dt><dd>35 mm SLR</dd></div>
        <div><dt>Production</dt><dd>1983 to 1994</dd></div>
        <div><dt>Lens mount</dt><dd>M42 screw mount</dd></div>
        <div><dt>Typical lens</dt><dd>Helios 58 mm f/2</dd></div>
        <div><dt>Meter</dt><dd>Dual LED XP indicator</dd></div>
        <div><dt>Weight</dt><dd>Approx. 0.95 kg</dd></div>
        <div><dt>Shutter</dt><dd>1/30 to 1/500, Bulb</dd></div>
        <div><dt>Film speed</dt><dd>ISO 16 to 500</dd></div>
      </dl>
      <p class="zenit-specplate__note">From Lomography review context, aligned with this archive.</p>
    </aside>

    <p>
      This one is a bit personal. The Zenit-12XP I own came into the family from Moscow in the 1980s and eventually
      landed with me, wearing a HELIOS-44M-4. It is the camera that taught me proper SLR photography: film, mirror,
      shutter, aperture ring, focus ring, wind lever, and no safety net. You could not spray and pray; you had to pick
      the shutter speed, pick the aperture, nail focus, and live with what came back from the roll. I took some really
      lovely photos with it, and I still have a soft spot for that thunk-and-whirr.
    </p>

    <p>
      The camera now needs work, which sent me looking for repair documentation worth trusting at the bench. A lot of
      English material I found was incomplete, weakly translated, or missing key diagrams. The useful source set turned
      out to be the original Russian Zenitcamera material: repair manual, user manual, and parts catalogue. That kicked
      this from “find a better manual” into a proper preservation job.
    </p>

    <p>
      We archived the source pages directly with a script, saved raw HTML snapshots, extracted structured content, and
      pulled both inline images and higher-resolution linked assets when they existed. Many of the most useful plates sit
      behind smaller preview images, so that step mattered. We also generated manifests and an image placement map so
      every figure, schematic, and catalogue plate traces back to source and reconnects to the right section.
    </p>

    <p>
      The first scrape missed key text because old character-encoding quirks distorted extraction, so we revisited the
      archived HTML, repaired Cyrillic extraction, rebuilt the Russian markdown, and remapped images carefully. In technical
      manuals, figure placement is not decoration; if diagrams drift away from the instructions that reference them, the
      manual becomes guesswork.
    </p>

    <p>
      The final set keeps the originals intact in structure while providing usable English technical translations:
      repair manual, user manual, parts catalogue, rebuilt Russian source markdown, manifests, glossary, notes, and
      complete archive packages. The PDFs are the easiest day-to-day bench references; the archive keeps the source
      chain verifiable and prevents it from disappearing behind broken links.
    </p>

    <p>
      Partly I did this because I want to fix my camera. Mostly I did it because old practical knowledge deserves better than
      link rot: workshop logic, exploded diagrams, parts references, and repair know-how should stay accessible, checkable,
      and usable.
    </p>
  </section>

  (() => {
    const root = document.querySelector('[data-zenit-app]');
    if (!(root instanceof HTMLElement)) return;

    const docs = {
      repair: {
        title: 'Repair Manual (PDF)',
        desc: 'English technical translation with original figure placement and repair references preserved.',
        href: '/docs/zenit-12xp/manuals_pdf/zenit-12xp_12sd_repair-manual_en.pdf',
        preview: true,
      },
      user: {
        title: 'User Manual (PDF)',
        desc: 'English user guide for operation, metering, loading, shooting, rewinding, and care.',
        href: '/docs/zenit-12xp/manuals_pdf/zenit-12xp_12sd_user-manual_en.pdf',
        preview: true,
      },
      parts: {
        title: 'Parts Catalogue (PDF)',
        desc: 'Parts and assembly catalogue with high-resolution diagram plates as authority.',
        href: '/docs/zenit-12xp/manuals_pdf/zenit-12xp_12sd_parts-catalogue_en.pdf',
        preview: true,
      },
      zip: {
        title: 'Complete Archive (ZIP)',
        desc: 'Full package including PDFs, markdown, source mappings, glossary, and notes.',
        href: '/docs/zenit-12xp/zenit-12xp_12sd_english_manual_archive.zip',
        preview: false,
      },
      toolkit: {
        title: 'Archiver Toolkit (ZIP)',
        desc: 'Toolkit archive containing the script package used for scraping and source archiving.',
        href: '/docs/zenit-12xp/zenit-12xp_zenitcamera_archiver_toolkit.zip',
        preview: false,
      },
    };

    const launcher = root.querySelector('#zenit-launcher');
    const runBtn = root.querySelector('[data-zenit-run]');
    const modal = root.querySelector('[data-zenit-modal-dialog]');
    const modalTitle = root.querySelector('[data-zenit-modal-title]');
    const modalDesc = root.querySelector('[data-zenit-modal-desc]');
    const modalLink = root.querySelector('[data-zenit-modal-link]');
    const modalFrame = root.querySelector('[data-zenit-modal-frame]');
    const modalViewerWrap = root.querySelector('[data-zenit-viewer-wrap]');
    const drawer = root.querySelector('[data-zenit-drawer]');

    const openModal = (key) => {
      if (!(modal instanceof HTMLDialogElement)) return;
      const item = docs[key];
      if (!item) return;
      if (modalTitle instanceof HTMLElement) modalTitle.textContent = item.title;
      if (modalDesc instanceof HTMLElement) modalDesc.textContent = item.desc;
      if (modalLink instanceof HTMLAnchorElement) {
        modalLink.href = item.href;
        modalLink.textContent = item.preview ? 'Download / open file' : 'Open source';
      }
      if (modalViewerWrap instanceof HTMLElement) {
        modalViewerWrap.hidden = !item.preview;
      }
      if (modalFrame instanceof HTMLIFrameElement) {
        modalFrame.src = item.preview ? item.href : 'about:blank';
      }
      modal.showModal();
    };

    const runCommand = (raw) => {
      const cmd = raw.trim().toLowerCase();
      if (!cmd) return;
      if (cmd === 'sources' || cmd === 'archive') {
        if (drawer instanceof HTMLDialogElement) drawer.showModal();
        return;
      }
      const item = docs[cmd];
      if (!item) {
        if (launcher instanceof HTMLInputElement) {
          launcher.value = 'Unknown command. Try: repair, user, parts, zip, toolkit, sources';
          launcher.select();
        }
        return;
      }
      if (item.preview) {
        openModal(cmd);
      } else {
        window.location.href = item.href;
      }
    };

    if (runBtn instanceof HTMLButtonElement && launcher instanceof HTMLInputElement) {
      runBtn.addEventListener('click', () => runCommand(launcher.value));
      launcher.addEventListener('keydown', (event) => {
        if (event.key === 'Enter') {
          event.preventDefault();
          runCommand(launcher.value);
        }
      });
    }


    root.querySelectorAll('[data-zenit-modal]').forEach((btn) => {
      if (!(btn instanceof HTMLButtonElement)) return;
      btn.addEventListener('click', () => openModal(btn.dataset.zenitModal ?? ''));
    });

    root.querySelectorAll('[data-zenit-switch]').forEach((btn) => {
      if (!(btn instanceof HTMLButtonElement)) return;
      btn.addEventListener('click', () => openModal(btn.dataset.zenitSwitch ?? 'repair'));
    });

    root.querySelectorAll('[data-zenit-drawer-open]').forEach((btn) => {
      if (!(btn instanceof HTMLButtonElement)) return;
      btn.addEventListener('click', () => {
        if (drawer instanceof HTMLDialogElement) drawer.showModal();
      });
    });

  })();
`}</script>
