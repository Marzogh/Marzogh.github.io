# Translation and Rebuild Notes

This English manual set was rebuilt from the Zenitcamera Russian HTML archive supplied by the archival source set.

Key preservation choices:

- Original part-position numbers are preserved.
- Instrument codes, material standards, GOST/TU references, and adjustment dimensions are preserved.
- The parts catalogue source page states that written specifications are not present. The catalogue therefore embeds the original 300 dpi figure plates as the authoritative catalogue content.
- TIFF images are retained in original format. For PDF compatibility, lossless PNG derivatives were generated from the TIFF files without resizing.
- The PDFs embed the highest-resolution local image data available in the archive. Original TIFF files are included alongside the PDF-compatible derivatives.
- This is a technical working translation, not a factory-issued English original.
