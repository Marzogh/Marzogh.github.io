# Zenit-12XP / Zenit-12SD English Manual Set

This package contains rebuilt English manuals based on the original Russian Zenitcamera archive.

## Contents

- `manuals_markdown/zenit-12xp_12sd_repair-manual_en.md`
- `manuals_markdown/zenit-12xp_12sd_user-manual_en.md`
- `manuals_markdown/zenit-12xp_12sd_parts-catalogue_en.md`
- `manuals_pdf/zenit-12xp_12sd_repair-manual_en.pdf`
- `manuals_pdf/zenit-12xp_12sd_user-manual_en.pdf`
- `manuals_pdf/zenit-12xp_12sd_parts-catalogue_en.pdf`
- `glossary/zenit-12xp_12sd_glossary_ru-en.md`
- `translation_notes/translator_notes.md`
- `images/` containing both original source images and PDF-compatible derivatives
- `source/` containing the original Russian rebuilt Markdown and manifest files

## Image handling

The highest-resolution images available in the archive were preserved. The original catalogue and repair schematic TIFF files are included. For PDFs, the TIFFs were converted to PNG at original pixel dimensions without resizing so they would embed and render reliably.

## Important note

This is a technical working translation and archival rebuild. It is not a factory-issued English original.
